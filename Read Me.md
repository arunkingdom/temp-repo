# 🛒 Amazon Sales Analytics Dashboard

An interactive Power BI dashboard designed to analyze Amazon sales data and uncover insights into sales performance, product categories, fulfillment, courier status, and regional demand.

---

## 1. Amazon Sales Analytics Dashboard


An interactive data visualization dashboard built using Power BI to explore Amazon sales performance, product demand, order fulfillment, courier status, and state-wise distribution.

---

## 2. Purpose

The Amazon Sales Analytics Dashboard is a Power BI report developed to analyze 40,000+ Amazon sales records and transform transactional data into meaningful business insights.

The dashboard helps users monitor sales performance, identify top product categories, analyze fulfillment and courier status, and understand regional order distribution.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Main platform used for dashboard development and visualization.
- 📂 **Power Query** – Used for data cleaning and transformation.
- 🧠 **DAX** – Used for calculated measures, KPIs, and analytical calculations.
- 🗄️ **SQL** – Used for data analysis, aggregation, and identifying business trends.
- 📝 **Data Modeling** – Used to structure data for analysis and interactive filtering.
- 📁 **File Format** – `.pbix` for the Power BI dashboard and `.png` for the dashboard preview.

---

## 4. Data Source

The project uses an Amazon sales dataset containing 40,000+ sales records.

The dataset includes information related to:

- Sales and order details
- Product categories
- Product sizes
- Courier status
- Fulfillment method
- Delivery partners
- Shipping states
- Order dates

> This is an independent analytics project and is not affiliated with or endorsed by Amazon.

## 5. Features / Highlights

### • Business Problem

Raw sales data can make it difficult to quickly understand product demand, order fulfillment, shipment status, and regional sales patterns.

The goal of this project was to convert transactional sales data into an interactive dashboard that provides a clear overview of key business metrics.

### • Goal of the Dashboard

The dashboard was designed to:

- Monitor overall sales performance
- Identify top-performing product categories
- Analyze courier and shipment status
- Compare fulfillment methods
- Understand product size distribution
- Analyze state-wise order distribution

### • Walkthrough of Key Visuals

- **Sales Amount KPI**  
  Displays the overall sales amount for the selected date range.

- **Courier Status**  
  Shows the distribution of orders across Shipped, On the Way, Cancelled, and Unshipped statuses.

- **Top 5 Categories**  
  Highlights the most frequently ordered product categories.

- **Delivery Partner**  
  Provides an overview of orders handled by delivery partners.

- **Fulfillment**  
  Compares orders fulfilled by Amazon and Merchant.

- **Size Analysis**  
  Shows order distribution across different product sizes.

- **Ship-State**  
  Visualizes order distribution across major Indian states.

- **Date Filter**  
  Allows users to interactively analyze the dashboard for a selected date range.

### • Business Impact & Insights

- **Sales Analysis:** Monitor overall sales performance and trends.
- **Product Analysis:** Identify high-demand product categories and sizes.
- **Operations:** Analyze fulfillment and courier status.
- **Logistics:** Understand delivery partner distribution.
- **Regional Analysis:** Identify states with higher order volumes.
